# 历史实现

这里保存早期里程碑与环境移植代码，用于回看设计和解释历史实验。
当前实现以 `../implementation/` 为准。

- `方法阶段_里程碑0/`：早期差分头、模型恢复文件。
- `方法阶段_里程碑1/`：早期适配器/门控训练版本。
- `方法阶段_里程碑2/`：锚点、局部冻结、回放合并与 BN 重校准工具。
- `方法阶段_MuJoCo扩展/`：早期环境配置与包装补丁。
- `protocol_notes_before_cleanup.md`：整理前的协议说明与操作记录，内部保留，不进入教师代码副本。

原 `方法阶段_里程碑3/module.py` 和 `train_lewm.py` 已原样迁至
`implementation/`，不再保留两份可编辑的当前版本。
旧的零初始化 `smoke_growth.py` 停用桩已删除，使用
`cl_protocol/test/growth_check.py` 检查实际非零旧槽和优化器更新。

历史训练文件中的缺陷不会因归档自动修复。复现历史实验需同时匹配当时的
模型、平台源码、预处理和配置；历史目录不作为另一套当前安装入口。
